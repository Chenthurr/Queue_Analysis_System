# Contributing

Queue Analysis System changes should preserve reliable people detection, tracking, ROI analysis, and queue metrics.

## Guidelines

- Add tests for changes to counting, tracking, thresholds, or data processing.
- Document assumptions around camera placement, frame rates, and ROI definitions.
- Do not commit recorded camera footage, credentials, or deployment secrets.
- Keep performance-sensitive processing measurable and avoid unnecessary per-frame work.

## Pull requests

Explain the problem, implementation, validation, and any accuracy or performance trade-offs.
